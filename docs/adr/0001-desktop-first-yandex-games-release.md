# Publish on Yandex Games as a desktop-first WebGL release

The game will first ship publicly on Yandex Games as a desktop-only WebGL build hosted by Yandex, with mobile support treated as a later release. The port will use an adaptive 16:9 presentation, browser-specific quality profiles, and platform-neutral gameplay actions so that reducing initial scope and graphics risk does not hard-code desktop input into the game architecture.
